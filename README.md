# Project_on_DataAnalysis
A Project in Data Analysis in Python  
A practical Python Data Analysis and EDA project focused on cleaning, preprocessing, analyzing, and visualizing real-world data.

**🎯 Project Objectives**

- Clean and preprocess raw data
- Handle missing values and duplicate records
- Correct data types
- Remove extra spaces and inconsistent text
- Perform data filtering and analysis
- Explore data using EDA
- Create meaningful visualizations
- Perform automated EDA

**🛠️ Technologies Used**
- Python
- Pandas
- NumPy
- Matplotlib
- AutoEDA
- Google Colab / Jupyter Notebook

**🔍 Key Topics Covered**
- Data Cleaning
- Missing Value Handling
- Duplicate Removal
- Data Type Conversion
- String Cleaning
- Data Filtering
- Exploratory Data Analysis
- Data Visualization
- Automated EDA


**📚 Learning Outcomes**

This project helped me gain practical experience in:
- Python-based data analysis
- Data cleaning and preprocessing
- Exploratory Data Analysis
- Data visualization
- Extracting insights from datasets
